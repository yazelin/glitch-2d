# 精修與換圖規格

這份規格的目的是讓精修素材沿用既有綁定。

## 繪製方式

1. 複製 `glitch.psd` 後再修改。保持 1196 × 3072 畫布，不裁切、不移動整個角色。
2. 保持同一站姿、頭身比例，以及眼睛、嘴巴、肩膀、手腕的位置。
3. 在既有圖層中精修，保留名稱、順序與可見範圍。不要合併原有圖層。
4. 頭髮遮住的臉、袖子遮住的衣服、手腕接縫要補畫完整，為動作保留重疊區域。
5. 眼皮 `22_lid_R`、`23_lid_L` 與開口 `42_mouth_A` 最需要改善。請沿原圖畫風重畫，保持眼、嘴中心位置。
6. `43_mouth_I`、`44_mouth_U`、`45_mouth_E`、`46_mouth_O` 未被目前模型採用；保留在來源 PSD 中即可，重新匯入時不要新增成模型物件。

## Cubism 中替換

1. 開啟 `glitch.cmo3`，另存副本。
2. 匯入精修 PSD，選擇在現有模型中替換原 PSD 的來源影像；不要選擇建立新模型。
3. 檢查每一層是否對應正確，再測試所有已綁定參數的最小值、預設值與最大值。
4. 若新線稿超出舊網格，調整該 ArtMesh 網格；若姿勢改變，調整受影響的變形器與關鍵姿勢。
5. 更新貼圖集，以「For SDK 5.0 / Cubism5.0」匯出至 `model/`。保留隱藏 ArtMesh，避免漏掉表情素材。
6. 執行 `python3 tools/build-motions.py`，補回 SDK 匯出時未包含的待機、揮手與參數群組設定。重新測試後再發布。

單純精修線條和上色通常能大量沿用。更換整個姿勢、頭身比例或髮型輪廓，則不能保證直接替換完成；現有變形器層級與控制程式仍可作為基礎。
